## 🚀 Featured Projects

### 🤖 [AI Investment Agent](https://github.com/Ramiassaf/ai-investment-agent) *(Active Build)*
An autonomous agent that monitors gold and silver markets using RSS ingestion, semantic search retrieval (FAISS + sentence embeddings), and structured LLM reasoning. Built day by day, documented as a learning series.  
`LangChain` `FAISS` `Semantic Search` `RSS Ingestion` `Multi-source Retrieval`

---

### ✈️ [AI Travel Assistant](https://github.com/Ramiassaf/ai-travel-assistant)
A multi-agent travel planner powered by CrewAI. Agents collaborate to find flights, hotels, and build itineraries — with a Streamlit UI and Docker deployment.  
`CrewAI` `Multi-Agent` `Streamlit` `Docker`

---

### 📄 [RAG Resume Assistant](https://github.com/Ramiassaf/rag-resume-assistant)
A retrieval-augmented generation system that answers questions about a resume using embeddings and vector search. Clean example of a production RAG pattern.  
`RAG` `Embeddings` `Vector Search` `OpenAI`

---

### 🫁 [Chest X-Ray Pneumonia Detector](https://github.com/Ramiassaf/CHESTXRAYPROJECT)
A CNN trained to detect pneumonia from chest X-rays. Covers data preprocessing, model architecture, training, and evaluation.  
`CNN` `Deep Learning` `Medical Imaging` `TensorFlow`
